# Simple Bot Start (BotStart)

An update of Trionicb's *Simple Bot Start* for Factorio 2.1 / Space Age
(Factorio 2.0 players: use version 0.3.0).

## What it does

Gives every player a full construction kit the moment they spawn, so a new map
starts at the point where building is fun rather than manual:

- Power Armor Mk.2
- 4x personal roboport mk.2 and 50 construction robots
- 4x portable fission reactor
- 2x battery mk.2
- 4x energy shield mk.2

## Changes from the original

Factorio 2.0 removed the portable fusion reactor and replaced it with the
portable fission reactor, which is what the mod now grants.

## Install

Drop `BotStart_0.3.0.zip` into `%APPDATA%\Factorio\mods`.
